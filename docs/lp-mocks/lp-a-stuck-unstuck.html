    Market Harness

    When an AI coding agent gets stuck, it can buy a human expert's sealed, human-approved answer by itself.

    The harness around the agent sets a budget, keeps payees on an allowlist and writes a receipt for every purchase. The first seller is the founder, with five approved lessons about operating AI coding agents.

    How it works What is verified

    How it works

    Four steps, one payment.

    1. 1

      The agent asks for a quote

      Stuck on a problem, the agent asks a human expert for a price. Asking is free and moves no money.

    2. 2

      The harness checks it

      Is the price inside the agent's budget? Is the payee on the allowlist? The check runs outside the agent's own process.

    3. 3

      A human signs one transaction

      One Solana transaction pays two recipients: 90% to the seller, 10% to the marketplace. Nothing moves without the human signature.

    4. 4

      The answer is released

      Only after the transaction is finalized does the sealed answer open. The agent gets the answer and keeps a receipt.

    By construction

    Declined = free.

    The quote costs nothing. The answer is released only by a transaction a human has signed and the network has finalized. If the human declines, no transaction exists, so there is nothing to charge.

    Stated at the strength of the evidence

    What is verified, and what is not yet.

    Seen on devnet devnet · test token

    Throwaway keys. Re-derived from the chain by a second path.

    • One transaction paid two recipients: seller +9000, marketplace +1000, payer −10000 atomic units.
    • A failing second leg moved nothing. Token deltas were 0; only the network fee was charged.
    • After a forced kill at five points, a later run returned the same answer and receipt, with no replacement transaction.
    • The five lessons were approved by the founder, then sealed with SHA-256 hashes.

    Not yet, not claimed open

    Listed so nobody reads more into the demo than it shows.

    • No mainnet purchase has happened. The founder-to-founder mainnet test is not completed.
    • A human-signed devnet purchase expired before broadcast (about 60 s to approve, about 37 s of blockhash life). No funds moved. A renewal path is tested but not yet run on a real terminal.
    • A small exploratory study detected no benefit from paid consultation. No claim of demand or revenue.
    • Runtime isolation of the seller worker and a live policy proof are not verified.
